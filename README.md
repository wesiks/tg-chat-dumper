# Telegram Restricted Chat & Media Dumper (TGdumb)

Прямое извлечение истории сообщений и всех типов медиафайлов из любых диалогов, закрытых групп и каналов Telegram через MTProto с обходом запрета на сохранение и копирование контента (`noforwards`).

## Возможности

- **Полный обход запрета на сохранение (`noforwards`):** Загрузка медиа напрямую через серверный бинарный поток MTProto (клиентские UI-ограничения игнорируются).
- **Выкачка всех категорий медиа:** Фотографии в исходном качестве, видео, круглые видеосообщения (видеозаметки), голосовые (.ogg), аудиофайлы (.mp3), стикеры и документы без сжатия.
- **Интерактивный TUI-интерфейс (Spectre.Console):** Навигация стрелочками `↑ / ↓`, живой поиск по названию/юзернейму, статус-панель активной загрузки со скоростью и прогресс-баром.
- **Докачка и пропуск:** Существующие файлы с корректным размером не скачиваются повторно.
- **Поддержка туннелирования (MTProxy):** Автоопределение локального `TgWsProxy` (`127.0.0.1:1443`) для стабильной работы при сетевых ограничениях.
- **Экспорт переписки:** Полная история сообщений сохраняется как в человекочитаемый `chat_history.txt` (транскрипт), так и в структурированный `chat_history.json`.

## Требования

- [.NET 10.0 SDK](https://dotnet.microsoft.com/)
- Windows / Linux / macOS

## Быстрый старт

1. Сборка и запуск:
```bash
dotnet run -c Release
```

2. При первом запуске:
   - Введите имя сессии (например `main`).
   - Авторизуйтесь по номеру телефона и коду из Telegram (поддерживается 2FA облачный пароль).
   - Выберите чат стрелочками `↑ / ↓` или воспользуйтесь поиском и запустите выгрузку.

## Структура выгрузки

Все данные сохраняются в папку `dumps/<НазваниеЧата_ID>/`:
```
dumps/
  └── ChatTitle_12345678/
      ├── chat_history.txt
      ├── chat_history.json
      ├── dump_summary.txt
      └── media/
          ├── photos/
          ├── videos/
          ├── round_video/
          ├── voice/
          ├── audio/
          ├── documents/
          └── stickers/
```
